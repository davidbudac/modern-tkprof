# TraceLens focus loop

Four seconds, 768 × 768, 30 fps. The chosen option C is preserved in `assets/option-c.png`; three clipped layers animate its original shapes without redrawing them.

The brackets gently focus inward, the small center square pulses to 110% with a four-degree tilt, and everything settles to the original pose. The opening and closing poses match for seamless looping. Reduced-motion browser settings show the resting mark.

`index.html` is the editable HyperFrames composition. It uses the local `assets/gsap.min.js` runtime. Use HyperFrames Studio to preview or edit the timing, and HyperFrames render to export MP4 or GIF.

Timing: rest 0–0.4 s; focus and pulse 0.4–1.2 s; settle 1.35–2.51 s; rest 2.51–4 s.
