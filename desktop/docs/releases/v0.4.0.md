# mtkprof desktop v0.4.0

Engine v0.4.0 (see its release notes: trace sets with a Files panel, live
sessions updating in place, the in-call idle fix; caches from v0.3.x are
rebuilt on first open).

- Open several trace files or a folder as one trace set: "Open files…" and
  "Open folder…" (also in the dev browser mode), drag and drop of a set;
  tabs titled `name (+N)` with a folder mark; the top bar shows "N files".
- Files side pane per tab with the selection, its open/closed state and
  width persisted in `workspace.json`; the inspector, Statements context
  and Lines panels get the same collapse tab and remember their state.
- Live tabs follow the engine's long poll (`followLive`): a "live · rev N"
  badge with pause/resume, scope and selection kept across updates,
  "ended" when the follow stops; background tabs keep following.
- A crash in one tab's view shows an in-tab error card with "Reload tab"
  and "Copy details" instead of taking down the shell.
- Settings → Backup: export and import connections and the library in one
  file (passwords are never written).
- Dev browser mode closes its engine sessions on reload.
- Installers are built locally (`scripts/release-local.sh`): DMG
  (arm64, x64), deb, AppImage, NSIS. macOS: "Not Opened" → Privacy &
  Security → Open Anyway on first start. Windows is untested.
