mtkprof — a chrome diet, not a redesign

Tokens, type and data colors stay exactly as they are; the identity is already right. What changes: the five stacked chrome bands around a trace collapse into two, and every fact they carried moves one hover away instead of being permanently on screen. Nothing is removed — the subbar, the status bar, the counts and the response mini-bar all survive as popovers or view-level details.

Where everything went. The subbar's facts (Oracle version, instance, session, module, span) and the file list move into one popover on the file name (mockup 2). The status bar disappears when the engine is healthy; its dot sits beside Settings and opens a popover with status, restarts, open traces, cache usage and Kill engine — when the engine is starting, restarting or failed, a one-line bar returns on its own. View-tab counts move into each view's own header (the Waits header already says "41 events"), the big response mini-bar shrinks to a 56 px sparkline that expands in the file popover, and the files chip rides on the file button. The filter row keeps its slot but drops the blue wash — chips carry the accent instead. Tab strip loses the boxed "browser tab" outline for a quiet raised pill; one hairline under the session bar replaces four.
