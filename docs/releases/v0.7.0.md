# mtkprof v0.7.0

The desktop app runs on a new shell: Electron instead of Tauri. It looks and
works as before, with the same Chromium on every system. It also runs on
Linux distributions the old shell did not support, such as Oracle Linux 9 and
RHEL 9. Your tabs, settings, notes, connections and index cache carry over.

## Moving from v0.6.0

- **macOS and Linux**: v0.6.0 offers this release as usual. *Install and
  restart* replaces it with the new app once (on Linux a `.deb` install asks
  for your password).
- **Windows**: install `mtkprof_0.7.0_x64-setup.exe` by hand. It removes the
  old app first and keeps your data.
- **API keys**: a key the old app remembered is taken over on macOS the
  first time it is needed. macOS asks you to allow mtkprof to use it. On
  Windows and Linux, type it once more.
- **Updates from now on**: the app still checks GitHub on start, but
  *Download* opens the release page. Install the new version over the old
  one. Installing in place is planned.
- **Downloads are bigger**: about 125 MB, against about 12 MB for the
  old shell.

## Desktop app

- Security: the app's page can read only the files you pick and the team
  connections file. It can write only your save-dialog choices and its own
  report and cut folders, and it opens only reports it just wrote. Electron's
  fuses are set: the app binary cannot run arbitrary scripts or take a
  debugger. The engine's cache cleanup deletes only folders the engine made.
- Folder picker: opening a folder lists its traces with a quick peek, and
  you choose which to open.
- Overview masthead: *Time in trace* with when, database, session and
  module beside it.
- Cut: one check at a time over a live session, a limit before writing, the
  statement picked from all of them, keyboard-operable piece labels, and every
  opened cut in a file of its own.
- Statements list, chat and note drafts keep their state per tab; tabs
  restore, and reopen after an engine restart, through a bounded queue.
- Keyboard and screen-reader support for the connections list, tables and
  resize handles.
