# mtkprof v0.5.0

The first release from one repository: the command-line binaries and the
desktop installers come from the same commit under the same tag (the
desktop app was `davidbudac/mtkprof-desktop`, now archived). Caches written
by v0.4.0 are rebuilt on first open (`CacheIndexFormat` 4).

## Assistant and Claude Code

- `mtkprof mcp`: the analysis tools as a stdio MCP server, e.g.
  `claude mcp add -s user mtkprof -- mtkprof mcp`. Traces open with
  `open_trace` or from the command line; bind values are masked by default
  (`-binds keep` to show them); SQL text is not masked.
- `mtkprof brief`: a short, scope-aware account of a trace (also
  `POST /s/{id}/api/brief`).
- Desktop: an assistant chat panel beside the views, over an
  OpenAI-compatible endpoint, the `claude` CLI, or `codex` (experimental).
  Answers cite trace lines as `mtkprof:` links, can move the view and can be
  saved as notes. API keys stay in the OS keychain, bound to their endpoint.

## Views (CLI report and desktop alike)

- Execution Loom: A/B comparison of two executions aligned by call
  checkpoints, with per-phase deltas, in-call waits by object and event,
  and wait records linked to their lines.
- Lines: folding of BINDS, STAT and long SQL, hover cards, an elapsed heat
  gutter, clock time and delta columns, a density strip, search presets and
  scopes, Go to line / cursor / sql_id / execution, an outline, structural
  stepping, a command palette and bookmarks.
- Timeline lanes: colour by call phase or resource, with a brush per phase;
  optional wait-class strips; zoom into a window; a lane click selects the
  time window and opens its lines.
- A filter row of the filters in force, full-width views, a one-column
  statement detail with plans above findings, and menus instead of button
  clusters.

## Desktop app

- Open traces from outside: double-click a `.trc` (the installers register
  the extension), Open With, drop on the Dock icon, or `mtkprof open
  a.trc dir/` in a terminal.
- Trace sets: open several files or a folder as one tab, with a Files pane;
  live tabs follow a growing trace ("live · rev N", pause/resume).
- View and tab shortcuts, Back and Esc on pages, Settings → Backup
  (connections and library; never passwords), and a per-tab error card
  instead of a broken window.

## Installing

Command line: the `mtkprof-*` binaries, checked with `SHA256SUMS`.
Desktop: `mtkprof_0.5.0_*` installers, checked with `SHA256SUMS-desktop`.
All builds are unsigned: on macOS use Privacy & Security → Open Anyway on
first start, on Windows "More info" → "Run anyway". See
<https://davidbudac.github.io/modern-tkprof/docs.html#install>.
