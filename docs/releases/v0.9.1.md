# mtkprof v0.9.1

A small release: the macOS keychain prompt after an update is gone, and the
statement view is reordered.

## Moving from v0.9.0

- **macOS**: the app no longer reads the keychain at every launch, so macOS
  does not ask to allow it again after an update. It reads the keychain only
  for remembered Assistant keys.
- **Caches**: the cache format is unchanged (`CacheIndexFormat` 9).

## Changes

- **Statements** (desktop, `mtkprof serve`, the HTML report): *Context* and
  *Recursive statements* are at the bottom of a statement's detail. *Waits*
  stays under the response time.
- **Trace tab**: the line drawer's button, the hint of a "line N" link and the
  time window's button now say *Trace*, the tab's name; they said *Lines*.
- **Desktop**: Electron's cookie encryption is off. The app sets no cookies,
  and this was what read the keychain at launch.
