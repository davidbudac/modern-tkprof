# mtkprof v0.6.0

The desktop app now updates itself: from this release on it checks the
GitHub releases on start and offers *Install and restart*. v0.5.0 has no
updater, so install v0.6.0 by hand once. Caches written by v0.5.0 are
rebuilt on first open (`CacheIndexFormat` 6).

## Desktop app

- Updates: a few seconds after start the app asks for a newer release and
  offers Install and restart, Later or Skip this version; Settings → About
  has the switch and *Check now*. Updates are signed; the app refuses one
  whose signature does not match its key or the release's version.
- Cut (Tools menu): write a new trace file from a part of the trace (the
  calls in a time window and the chosen sessions or files, or one
  statement's calls), never splitting a call, with what the kept lines need
  (header, SQL text, plans) and bind values kept, masked or dropped; a map
  shows where each block of the new file comes from. Several files with no
  window join into one, like `trcsess`.
- Settings redesigned: sections as cards with a live preview of the bind
  settings, a sticky section index, theme tiles.
- View tabs that do not fit move into the Tools menu; Open in plan viz opens
  the system browser again.

## Trace (Lines) view

- Formatted mode: every line kind parsed and laid out as tables (plans,
  binds, waits), Duration on a log scale with Δ as the unexplained gap, runs
  of waits folded, a labelled overview bar.
- Highlight one or more statements in their own colour, a statement filter
  that keeps the folds, a line map of the highlighted statements, a SQL band
  that shows the statement pretty-printed.
- Colour the lanes by a dimension; a Δ filter (highlight or filter);
  ⌘/Ctrl+click and Shift build a set of lines that the status bar sums and
  `y` copies.
- `tim=0` is no time: clock, delta, gaps and folds skip it.

## I/O map, Row flow, Dialogue

- I/O map (was Blocks, ⌘I): the block address space of the I/O waits with
  zoom, object names, colour modes, a density layer, Hot blocks, Objects and
  Statements tabs.
- Row flow: a Sankey of a plan dump in the statement inspector; the plan
  advisor compares A-Rows with its estimate.
- Dialogue: a sequence diagram of one execution.
- Import names without a database connection: a read-only script whose
  pasted output names the objects and datafiles; it applies to every open
  tab of the same trace.

## Engine and CLI

- Control file waits are not counted as block I/O; 23ai's
  `obj#=4294967295` reads as -1.
- A new statement closes the previous one's open execution.
- `install.sh`: one curl installs the binary on Linux, macOS, AIX and
  Solaris.

## Installing

Command line: the `mtkprof-*` binaries, checked with `SHA256SUMS`.
Desktop: `mtkprof_0.6.0_*` installers, checked with `SHA256SUMS-desktop`
(the `.app.tar.gz`, `.sig` and `latest.json` files are for the updater).
All builds are unsigned: on macOS use Privacy & Security → Open Anyway on
first start, on Windows "More info" → "Run anyway". See
<https://davidbudac.github.io/modern-tkprof/docs.html#install>.
