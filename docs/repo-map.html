modern-tkprof and its desktop sibling

The engine repo holds all analysis and the shared UI. The desktop repo is a Tauri shell that pins it as a submodule and runs it as a sidecar.

modern-tkprof: reach for it when

  • you touch the parser, the model or tkprof-parity numbers
  • you want one binary on a DB server (report, html, serve)
  • you change any view: web/src/lib lives here
  • you change /api/*: edit the OpenAPI file and bump engine.Protocol

mtkprof-desktop: reach for it when

  • you work with many traces in tabs on a laptop
  • you need saved connections, Notes, Reports, the Library
  • you change the window, the sidecar lifecycle or keychain use
  • then bump the submodule pin; installers come from scripts/release-local.sh

Where they meet

  • Process: Tauri spawns mtkprof-engine
  • Wire: HTTP + SSE, bearer token
  • Code: @lib through engine/
  • Releases: both at v0.4.0 (2026-10-25)
